## 1. 배경과 문제

국내 거주자가 코인을 거래할 때 흔한 흐름은 다음과 같다.

1. **국내 거래소**에서 원화(KRW)로 **USDT(테더)** 매수  
2. USDT를 **해외 거래소**로 전송  
3. 해외 거래소에서 알트/BTC 등 **매매**  
4. 현금화 시: 해외에서 코인 매도 → **USDT로 회수** → **국내 거래소로 전송** → 국내에서 USDT **매도(원화 환전)**

문제는 다음과 같다.

- 국내·해외 거래소 내역이 **서로 다른 파일 형식**(빗썸 PDF, 바이낸스 XLSX, OKX CSV 등)으로 흩어져 있다.
- 전송(입출금)과 매매를 연결해 **실제 취득가·양도가·손익**을 잡기 어렵다.
- 2027년 1월 1일 이후 양도·대여분에 대해 **가상자산 기타소득(분리과세)** 신고가 예정되어 있어, 연간 손익 통산·기본공제·예상 세액 정리가 필요하다.

**CoinTax**는 위 원본 서류(PDF/XLSX/CSV)를 가져와 거래를 정규화·매칭하고, 신고용 요약과 예상 세금을 보여주는 macOS 앱이다.

## 2. 제품 목표

### 2.1 핵심 목표 (Must)

1. 국내·해외 거래소 **원본 import** (빗썸 PDF · 바이낸스 XLSX · OKX CSV)
2. 입출금(전송) 내역 **체인 간 매칭** (국내 출금 ↔ 해외 입금, 반대 방향 포함)
3. 자산별 **포지션·취득원가·실현손익** 계산
4. 과세연도 기준 **기타소득 요약 리포트** 생성
5. **예상 세액** 표시 (국세 20% + 지방소득세 2% 옵션 포함)
6. 모든 원본·계산 결과 **기기 로컬 저장** (서버 전송 없음)
7. **현재 보유** 코인·수량·평단가 표시
8. 계산 후 **정합성 검증 통과** 시에만 신고용 결과 확정

### 2.2 부가 목표 (Should / Later)

| 우선순위 | 목표 |
|----------|------|
| Must | 거래소 프리셋: **빗썸, 바이낸스(현물), OKX(현물)** + 제네릭 매핑 |
| Should | 신고용 표·CSV/PDF export |
| Should | 다중 계정 (빗썸+바이낸스, 빗썸+OKX, 동시 3소) |
| Could | 미실현 손익 대시보드 |
| Must | 과세용 **기준환율** 자동 조회 + 누락일 수동 입력 |
| Won’t (v1) | 거래소 API 동기화, 선물/마진, 자동 신고 제출, iOS/웹, App Store 배포 |

## 4. 핵심 사용자 시나리오

### S1. 첫 설정 및 원본 업로드

1. 앱 실행 → 과세연도 선택 (예: 2027)
2. 「국내」→ 빗썸 **거래내역 확인서 PDF** (엑셀 없음)
3. 「해외」→ 바이낸스 **Spot XLSX** 및/또는 OKX **Trading History CSV**
4. 자동 포맷 인식 → import 결과: 성공 N건 / 스킵·오류 M건
5. 오류는 행·페이지·사유와 함께 재업로드 유도
6. 바이낸스 Spot only 시 **입출금 파일 필요** 경고

### S2. 전송(브릿지) 매칭 확인

1. 국내 USDT 출금 ↔ 해외 USDT 입금 후보를 자동 제안
2. 사용자가 수락/수정/수동 연결
3. 미매칭 전송은 「미연결」 목록에 남아 경고

### S3. 손익·세금 리포트 확인

1. 과세연도 선택 후 「계산」
2. 코인별 실현손익, 총수입·필요경비, 기본공제, 과세표준, 예상 세액 표시
3. 거래 단위 상세 드릴다운
4. CSV/PDF로보내기

### S4. 추가 거래 반영

1. 새 기간 원본 append import
2. 중복 거래 감지(거래ID·시간·수량·해시 등)
3. 재계산 후 리포트 갱신

## 7. 범위

### 7.1 In Scope (v1)

- 현물 매수/매도, 입출금, 거래 수수료
- USDT 브릿지(빗썸 ↔ 바이낸스/OKX)
- 계정별 이동평균·FIFO 원가 + 기타소득 요약·예상 세액
- 멀티 포맷 import (PDF/XLSX/CSV), 기준환율 자동/수동

### 7.2 Out of Scope (v1)

| 항목 | 이유 |
|------|------|
| **선물·마진·펀딩** | 사용자 확정: v1 완전 제외 |
| 디파이·온체인 전체 지갑 추적 | 별도 인덱서 필요 |
| NFT | 과세·평가 이슈 별도 |
| 거래소 API 실시간 동기화 | 키 관리·약관·복잡도 |
| 국세청 홈택스 자동 제출 | 공식 API/정책 부재 |
| Mac App Store / 공증 배포 | 1차 로컬 개인 사용 |
| 세무 확정 자문 | 법률 영역 |

### 7.3 명시적 가정

1. 사용자는 **거주자 개인**, 앱은 **로컬 개인 사용**.
2. 표시·합산 통화는 **KRW**.
3. USDT는 v1에서 **USD 1:1** 후 **당일 USD 기준환율** 적용 (설정으로 고지).
4. 에어드롭 등은 「기타 취득」 단순 규칙 (세부 해석은 사용자 책임).

## 10. 수용 기준 (Acceptance Criteria) — MVP

MVP는 아래를 모두 만족할 때 완료로 본다.

1. [x] 빗썸 PDF · (바이낸스 XLSX 또는 OKX CSV) 합성 fixture import 가능
