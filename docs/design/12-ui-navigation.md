## 1. 정보 구조

```text
NavigationSplitView
├── Sidebar
│   ├── 대시보드
│   ├── Import
│   ├── 거래내역
│   ├── 전송 매칭
│   ├── 보유
│   ├── 리포트
│   └── 설정
└── Detail + (optional) Inspector
```

macOS 15+ 네이티브 패턴. 한국어 UI.

---

## 2. 화면별 책임

| 화면 | 핵심 |
|------|------|
| 대시보드 | 예상세, 검증 배지, 미매칭 수, 보유 요약 |
| Import | PDF/XLSX/CSV 추가, 포맷 배지(빗썸·바이낸스·OKX), 오류·페이지, 선물 제외, 바이낸스 입출금 경고 |
| 거래내역 | 필터 테이블 |
| 전송 매칭 | 제안/확정 |
| 보유 | 코인·수량·평단(KRW)·총원가·계정 drill-down |
| 리포트 | 세금 표, 의제 표, 고지, export (검증 게이트) |
| 설정 | 환율, 가정 문구 읽기, 정책 ID 표시 |

---

## 3. 검증 UX

```text
[ 검증 통과 ]  녹색
[ 경고 있음 ]  노랑 — export 가능(설정)
[ 검증 실패 ]  빨강 — export 비활성, 이슈 리스트
```

이슈 행 클릭 → 관련 거래/매칭 화면.

---

## 4. 필수 고지 카피

상수 모듈 `TaxCopy`:

| 키 | 문구 |
|----|------|
| notTaxAdvice | 본 결과는 세무 자문이 아닙니다. … |
| transferCost | **전송 소실 원가는 공개 세법 해설이 없어, 과다 공제를 피하기 위해 필요경비·도착 취득가에 넣지 않습니다. 세액이 다소 커질 수 있으며 세무 자문이 아닙니다.** |
| usdtPeg | USDT는 USD 1:1로 가정 후 기준환율을 적용합니다. |
| costMethods | 빗썸 이동평균, 해외 거래소 선입선출 … |

리포트 상단·export 푸터·설정 “계산 가정”에 동일 소스.
