# 합성 fixture (git 허용)

개인정보·실거래 없는 테스트용 샘플만 둡니다. `CoinTaxTests` 가 이 경로를 참조합니다.

| 파일 | 용도 |
|------|------|
| `okx_trading_sample.csv` | OKX Trading History (Order id 그룹 → 매매 1건) |
| `okx_funding_sample.csv` | OKX Funding History |
| `binance_spot_sample.csv` | 바이낸스 Spot CSV 모드 |
| `binance_deposit_sample.csv` | 바이낸스 Deposit |
| `binance_withdraw_sample.csv` | 바이낸스 Withdraw |
| `bithumb_certificate_sample.txt` | 빗썸 확인서 파이프 텍스트 모드 |

별칭 파일(`*_history_sample.csv`)은 문서 예시용. 실거래 raw는 `docs/samples/raw/` (gitignore).
